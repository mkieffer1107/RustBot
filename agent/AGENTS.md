# How you work (rules for the coding agent)

You are an autonomous software engineer in a Linux terminal. Nobody answers questions during a run. Your job is the
port described in `agent/SPEC.md`, in the order of `agent/TASKS.md`.

## Each session
1. Read `agent/SPEC.md`, this file, `agent/TASKS.md`, then the end of `agent/PROGRESS.md`.
2. Run `agent/checks/check_all.sh --quick` to see the current state.
3. Pick the first unfinished milestone (or the task `PROGRESS.md` says is next). Work in small steps.
4. Before you stop or when about 20 steps have passed since the last note, append to `PROGRESS.md`:
   date, milestone, what changed, check results (numbers), what failed and why, the exact next step.
5. Commit often: `git add -A && git commit -m "<milestone>: <what>"`. Never rewrite history, never force-push.

## Rules
- **Never edit** `agent/checks/`, `reference/`, or `agent/SPEC.md`. If a check looks wrong, write why in
  `PROGRESS.md` under "Check disputes" and move on to something else.
- Do not embed a Python interpreter (pyo3, RustPython, CPython, Pyodide) and do not copy recorded replies or goldens
  into the Rust sources. The grader uses hidden conversations; special-casing the dev corpus fails there.
- Fix the translator (`rustbot/tools/py2rs/`) rather than generated code whenever a fix applies to more than one site.
  Generated files carry a header `// @generated by py2rs from bot/<path>.py`; hand-written overrides go in
  `crates/bot/src/manual/`.
- Prefer the smallest failing case: `check_modules.sh --module <name> --first-failure` prints the call's input
  memory, Python's result and yours.
- Long commands: put a `timeout` on anything that could hang (`timeout 1800 cargo build --release`).
- Pin `wasm-bindgen` to the exact version of the installed `wasm-bindgen` CLI (`wasm-bindgen = "=X.Y.Z"`).
- Keep the repository buildable at every commit (`cargo build` passes), even if checks fail.
- Disk: use `target/` inside the repository only; delete nothing outside it.

## Tools available
`cargo`/`rustc` (stable, with `wasm32-unknown-unknown`), `wasm-pack`, `wasm-bindgen`, `wasm-opt` (binaryen), `node`,
`bun`, `python3.14` (with `PYTHONHASHSEED=0` set by the checks), `uv`, `git`, `rg`, `fd`, `jq`, `hyperfine`, `samply`,
`perf` (if the node allows), `chromium` (headless, for `check_space.sh`).
